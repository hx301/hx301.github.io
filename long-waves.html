海洋中的长波分类

先问什么力把水拉回平衡，再看旋转、层结和边界——一张分类树 + 一张表。

一句话

海洋里的“长波”不是一种波，而是一个家族：重力波、罗斯贝波、开尔文波、赤道波……分类的第一问是：什么力把它拉回平衡？

把“长波”当成一个东西，就会把潮汐、海啸、罗斯贝波、ENSO 混在一起。先按恢复力分，再按旋转、层结、边界加条件，就清楚了。

先定标准：两种“长波”说法

① 浅水长波：波长 ≫ 水深，c=√(gH)，非频散；潮汐、海啸、假潮。

② 物理海洋里的长波：波长几百到几千公里、周期几天到几年；罗斯贝波、开尔文波、赤道波。

判断“长”不只看波长，还要看它相对什么：相对水深、相对层结、相对地球自转。

分类树：先看恢复力，再看边界

海洋长波

重力波

恢复力：重力 / 浮力
  • 表面重力长波：潮汐、海啸、假潮
  • 内重力波：内潮、南海内波
快：分钟–天；c=√(gH) 或 √(g'H)

旋转波

恢复力：β / 位涡
  • 行星罗斯贝波
  • 地形罗斯贝波 / 陆架波
慢：周–年；罗斯贝波相速向西

边界陷波

旋转 + 边界（岸/赤道）
  • 沿岸开尔文波
  • 赤道开尔文波
  • 赤道罗斯贝波
  • 混合罗斯贝-重力波
被岸或赤道“拴”住，沿边界传播

正压 vs 斜压是另一条分类轴：正压整层同相，海面信号大；斜压靠密度面起伏，海面信号小、内部大。

三条主线：分类时最有用

重力 vs 旋转

重力波快（分钟–天），旋转波慢（周–年）；重力波可以非频散，罗斯贝波频散。

正压 vs 斜压

正压=整层同相，海面信号大；斜压=密度面起伏，海面信号小、内部大。

自由 vs 陷波

自由波可传远；陷波被岸或赤道“拴”住，沿边界传。

几个够用的公式

浅水长波

c = √(gH)

非频散；潮汐、海啸、假潮。H 是水深。

内波

c = √(g'H)，g' = g Δρ/ρ

斜压；海面信号小，密度面起伏大。

行星罗斯贝波

ω = −βk/(k²+l²)，c_x = ω/k < 0

相速向西；长波快、短波慢。

开尔文波

c = √(gH)

边界法向地转平衡；被陷在边界附近，衰减尺度为变形半径。

赤道波

c = √(gH)，用赤道变形半径

开尔文波向东，罗斯贝波向西。

五步判断流程

拿到一个“长波”现象，按顺序问五个问题：

  1. 波长 ≫ 水深？→ 浅水重力长波（潮汐 / 海啸 / 假潮）。
  2. 层结重要？→ 内波 / 斜压（内潮、南海内波）。
  3. 地球自转重要？→ 旋转波（罗斯贝 / 开尔文）。
  4. 有岸或赤道？→ 陷波（沿岸 / 赤道开尔文、赤道罗斯贝）。
  5. 地形重要？→ 地形罗斯贝波 / 陆架波。

常见误区

  • “长波”不是一种波。先问恢复力：重力、浮力、β，还是边界？
  • 罗斯贝波相速向西，不代表能量只能向西。短波的群速可以向东。
  • 开尔文波不是普通重力波。它是旋转 + 边界下的地转平衡波。
  • 潮汐是长波，但周期由天文强迫决定。它是受迫波，不是自由波。
  • 海啸在深海是浅水长波：速度快、振幅小；近岸变浅才放大。

30 秒复述

  1. 长波分类的第一问是什么？
  2. 罗斯贝波为什么向西？
  3. 开尔文波为什么被“拴”在边界？

能用自己的话答出这三句，分类就不是背名词了。

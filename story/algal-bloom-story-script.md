# 小藻的水下派对

两分钟原创科普动画，面向没有专业背景的观众。用拟人化角色、深色背景、颜色明确的图形和逐步展开的因果关系讲解藻类水华。

**成片参数：** 1920 × 1080，横屏 16:9，24 fps，时长 120 秒；H.264 视频、AAC 中文合成配音；画面同屏显示中英双语字幕。

**故事主线：** 小藻原本维持水下生活 → 多余营养到来 → 增殖与聚集 → 缺氧风险 → 综合防控 → 恢复平衡。

## 分镜与配音稿

### 00–09 秒｜小藻的水下派对

画面：镜头靠近小藻；小藻眨眼、开口回应，建立主角。

**旁白：** 湖水突然变绿，是谁干的？

**小藻：** 我叫小藻，先别急着怪我！

### 09–23 秒｜先认识一下：水里的生产者

画面：太阳、藻类、浮游动物和鱼类逐步连接，解释能量传递；氧气气泡上升。

**旁白：** 藻类本来是水里的生产者。靠阳光制造食物，释放氧气，还养活浮游动物和鱼类。

**旁白：** 常说的蓝藻，其实是蓝细菌。

### 23–36 秒｜一天，一桌营养送上门

画面：氮 N、磷 P 沿径流进入水体；小藻用对白回应。

**旁白：** 一天，多余的氮和磷随径流进入水里，像给小藻送来了一大桌营养。污水排放，也可能带来这些营养。

**小藻：** 开饭啦！

### 36–53 秒｜伙伴，越来越多了

画面：细胞逐渐增加；将生物量变化拆成“增加”和“减少”。

**旁白：** 再遇上适宜的光照和温度，藻类就可能加快生长。但不同的藻，喜欢的条件并不相同。

**旁白：** 把藻量想成一本账：增加持续超过减少，就会越积越多。

### 53–67 秒｜等等，也可能只是挤到一起

画面：同一组 64 个示意细胞移动到岸边；细胞数保持不变，解释物理聚集。

**旁白：** 风和水流，还会把已有的藻推到一起。看，数量没变，只是站得更挤了。

**旁白：** 岸边变绿，不一定等于全湖都长出了新藻。

### 67–77 秒｜这，就是水华

画面：用湖泊、海洋两幅水体示意解释水华概念。

**旁白：** 当藻类大量增长或聚集，局部浓度明显升高，就是水华。湖泊和海洋里，都可能发生。

### 77–93 秒｜热闹过头，氧气却少了

画面：藻层遮光；死亡藻体下沉；分解者出现；溶氧示意下降，小鱼开口。

**旁白：** 但热闹过头，就有麻烦了。藻太多会遮光；大量藻体死亡后，微生物分解它们，又会消耗氧气。即使水变清了，风险也未必结束。

**小鱼：** 我快喘不过气了。

### 93–102 秒｜有害，不一定等于有毒

画面：并列呈现“过量藻体导致遮光或缺氧”和“部分种类产毒”两条路径。

**旁白：** 还有些种类会产毒。不过，不是每次水华都有毒；不产毒，也可能造成缺氧。

### 102–114 秒｜让水里的生活恢复平衡

画面：减小营养输入、保护岸带、持续监测依次出现。

**旁白：** 怎么办？减少多余营养进入水体，保护湿地和岸带，持续监测藻类、氧气和必要的毒素。

### 114–120 秒｜小藻不是敌人

画面：小藻和小鱼回到同一画面，以保持平衡收束故事。

**旁白：** 目标不是消灭小藻，而是让水里的生活，重新保持平衡。

## 科学表达的边界

- 小藻和小鱼是拟人化角色，细胞大小、颜色、数量和仪表均为概念示意，不是真实观测或预测。
- “营养大餐”比喻氮、磷供应增加，不表示藻类像动物一样吞食肥料。
- 图中的食物关系是简化示意，不代表完整食物网。
- 水华可以由增长和聚集共同形成，水色不能直接用于判断毒性。
- 蓝藻属于蓝细菌；并非所有水华都产毒，非产毒水华也可能造成危害。
- 缺氧仪表没有数值刻度，不应作为水质判断标准。

## 制作说明

- 应用 Scientific Visualization 技能的科学表述、颜色语义及图形审核原则。
- 使用 Python / Pillow 逐帧绘制原创几何角色和动态图形，FFmpeg 编码。
- 配音为 Microsoft 中文合成声音：Yunxi（旁白）、Xiaoxiao（小藻）、Yunjian（小鱼）；未使用真人声音克隆。
- 音效是程序合成的轻音符；没有使用商业音乐、外部视频素材、创作者角色或标识。
- 视觉参考数学科普动画的深色背景、图形推演和颜色区分方式，故事、图形与文案为本次独立制作。
- 动画源文件包含在配套 ZIP 中，可修改旁白、字幕、颜色、分镜和时间安排。
